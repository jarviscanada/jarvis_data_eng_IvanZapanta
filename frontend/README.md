# Frontend Apps

This project is a trading application created in React.js and Vue.js 3:

1. [React Trading App](./react-trading-app) - a trading application built with React, featuring a modern, responsive interface and interactive features.

2. [Vue Trading App](./vue-trading-app) - a trading application built with Vue 3, utilizing the framework’s reactive data-binding and component-based architecture.

Both apps are designed to provide a seamless user experience with real-time data handling for trading scenarios.
